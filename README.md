# livingbrushexperience.com: reports notebook

Session reports from the Builder (Claude Code) for livingbrushexperience.com, so the Project Manager can check the work.

- Every report lives in `reports/` and is named `YYYY-MM-DD-short-name.md`.
- `reports/INDEX.md` lists every report, newest first. A report not in the index does not count.
- This notebook is public. Reports never contain keys, passwords, email addresses, server names, or client or operator names.
